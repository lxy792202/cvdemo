# 商品主图优选与智能扩图 Skill

## 功能

从一个产品图片文件夹中收集所有已经完成前置处理的图片，使用多模态模型选择最美观的一张商品图片，并调整为4:3比例。

## 输入

- input_dir：处理完成的商品图片文件夹
- output_dir：最终主图输出目录

## 执行流程

1. 递归读取文件夹中的所有有效图片。
2. 使用 Qwen 多模态模型比较图片。
3. 选择商品完整度、清晰度、构图、背景和商业美观度综合最佳的图片。
4. 使用 Pillow 判断图片是否为4:3。
5. 如果已经是4:3，直接保留。
6. 如果不是4:3，计算扩图画布。
7. 调用 Seedream 5.5 完成背景扩展。
8. 检查最终图片比例。
9. 保存最终主图和选择记录。

## 输出

- main_image.png：最终商品主图
- selection_result.json：主图选择和扩图记录

## 调用约束

- 必须等待前置图片处理任务全部完成。
- 只对处理成功的图片进行主图优选。
- 不允许对每张图片分别执行扩图。
- 只允许最终选中的一张图片进入扩图流程。
- 已经符合4:3比例的图片不得调用扩图模型。
- 不得裁切或拉伸商品主体。
